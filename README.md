# FitLog

FitLog is a responsive workout library and planning application built with Next.js. It allows users to browse workouts, view workout details, create a daily workout plan, save workouts for later, and track completed exercises.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- REST API
- LocalStorage

## Features

- Browse workouts from a REST API
- View detailed workout information
- Add workouts to today's plan
- Save workouts for later
- Mark workouts as completed
- Remove workouts from the plan or saved list
- Maximum five workouts in today's plan
- Sort workouts by duration, calories, or rating
- Responsive design for mobile, tablet, and desktop
- LocalStorage persistence
- Loading animation
- Custom 404 page
- Toast notifications
